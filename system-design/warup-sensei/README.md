# System Design — serie de Warup Sensei

Notas de la [playlist de YouTube](https://www.youtube.com/watch?v=SqcXvc3ZmRU&list=PLMCXHnjXnTnvo6alSjVkgxV-VH6EPyvoX) (25 videos). Un archivo por video, en formato de píldoras con analogías y diagramas Mermaid, pensado para ir de junior a senior/arquitecto.

## Convenciones

- Archivo: `NN-tema.md`, con `NN` = posición del video en la playlist.
- Cada archivo cierra con **"Lo esencial"** (repaso de 30 s) y una tabla problema → solución.
- Lo que ya está explicado en otro módulo del repo se enlaza, no se repite.
- Si un video es solo una variante del anterior, se fusiona en el mismo archivo.
- Las imprecisiones del video se marcan con **⚠️ Ojo**.
